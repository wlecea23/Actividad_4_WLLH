  
## Descripción del proyecto  
  
Comparación de modelos preentrenados para clasificación de imágenes sobre el dataset CIFAR-10 utilizando la plataforma Hugging Face y ejecución acelerada mediante GPU en Google Colab.  
  
## Objetivos  
  
* Evaluar modelos preentrenados.  
* Comparar precisión y eficiencia.  
* Identificar la mejor alternativa para el caso de uso propuesto.  
##   
## Modelos evaluados  
  
1. aaraki/vit-base-patch16-224-in21k-finetuned-cifar10  
2. luke12121212/cifar10-vit-classifier  
3. pfpdostudent/deit-tiny-cifar10-lab
